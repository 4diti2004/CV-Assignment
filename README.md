# Computer Vision – CCA 3 Assignment

## 📌 About

Welcome to my Computer Vision project repository! This repository contains the implementation of various Computer Vision techniques as part of my CCA 3 practical assignment.

The project demonstrates image processing, image segmentation, feature extraction, object recognition, and motion estimation using Python and OpenCV.

## 🎯 Project Objectives

- Understand fundamental Computer Vision concepts.
- Perform image restoration and segmentation.
- Extract and match image features.
- Implement object detection and recognition techniques.
- Analyze motion in video sequences.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Libraries:** OpenCV, NumPy, Matplotlib, Scikit-image
- **Deep Learning:** YOLO
- **Environment:** VS Code / Jupyter Notebook
- **Version Control:** Git and GitHub

## 📚 Project Tasks

### Task 1: Image Restoration and Segmentation

- Image restoration and enhancement.
- Thresholding and morphological operations.
- Canny edge detection.
- Watershed segmentation.

### Task 2: Feature Extraction and Matching

- Histogram of Oriented Gradients (HOG).
- Scale-Invariant Feature Transform (SIFT).
- Feature detection and matching.

### Task 3: Object Detection and Recognition

- Haar Cascade classifier.
- YOLO-based object detection.

### Task 4: Motion Detection and Estimation

- Frame differencing.
- Background subtraction using MOG2.
- Lucas–Kanade optical flow.

## 📂 Repository Contents

This repository contains the source code, notebooks, project output images, and project documentation related to the Computer Vision CCA 3 assignment.

## ▶️ How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/4diti2004/CV-Assignment.git
   ```

2. Open the project folder in VS Code.

3. Install the required Python libraries according to the project imports:

   ```bash
   pip install opencv-python opencv-contrib-python numpy matplotlib scikit-image
   ```

4. Open the project notebook or Python files.

5. Run the cells or scripts to view the results.

   *Note: Install any additional dependencies required by the YOLO implementation.*
